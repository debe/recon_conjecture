## 1. Setting: aligned pairs and the difference matrix

Let σ be a hypomorphism G → H with card isomorphisms f_x : G − x ≅ H − σx. Pull H back along
σ: H′ is the graph on V(G) with H′.Adj x y ⇔ H.Adj (σx) (σy). Then G − x ≅ H′ − x for every x
(an **aligned pair**), and G ≅ H ⇔ G ≅ H′. Write A, A′ for the adjacency matrices and

    Δ = A − A′        (symmetric, zero diagonal, entries in {−1, 0, 1}).

Every lemma of the fleet is a constraint on Δ. This is the common language of the synthesis.

| Source | Constraint on the aligned pair |
|---|---|
| degrees (checked `kelly_degree_sequence`, same σ) | Δ·1 = 0 |
| lemma B of t2 (neighbour-degree counts) | Δ·1_{D_k} = 0 for every degree class D_k |
| S3 below | diag(A^k) = diag(A′^k) for all k |
| S4 below (Godsil–McKay) | Δ·A^k·1 = 0 for all k |
| D2 below | G ∈ Q ⇔ H′ ∈ Q |
| goal | some relabelling inside the classes of isomorphic cards makes Δ = 0 |

Note the last row. Δ = 0 is more than is needed: if x and y have isomorphic cards, composing σ
with the transposition (x y) gives another aligned pair. The spectral chain only ever proves
Δ = 0, so it can only succeed when isomorphic cards are rare (§6, attempt 1).

## 2. Chain S: from Kocay to the walk matrix (all n ≥ 3)

Notation: ind(F, X) = number of vertex subsets of X inducing a copy of F. φ(X; x) =
det(xI − A_X). The checked `conj_kelly_ulam__disconnected__kelly_induced_count` ("Kelly")
says ind(F, G) = ind(F, H) for |F| < n.

### S0. Partition counts (Kocay's lemma, induced form)

**Claim.** Let r ≥ 2 and F₁, …, F_r be graphs with |F_i| ≥ 1 and Σ|F_i| = n. The number of
ordered tuples (S₁, …, S_r) of pairwise disjoint vertex sets with G[S_i] ≅ F_i is the same
for G and H. Hence for every isomorphism-invariant weight g (values in any commutative ring)

    P_g(G) := Σ over set partitions π of V with ≥ 2 blocks of  Π_{S ∈ π} g(G[S])

is the same for G and H.

Paper argument. Tuples with G[S_i] ≅ F_i and no disjointness condition number
Π_i ind(F_i, G). Since Σ|S_i| = n, a tuple is pairwise disjoint iff ⋃S_i = V. Inclusion–
exclusion over the set T of uncovered vertices:

    #{covering tuples} = Σ_{T ⊆ V} (−1)^{|T|} Π_i ind(F_i, G − T).

T = ∅: every |F_i| < n because r ≥ 2, so Kelly gives each factor. T ≠ ∅:
Σ_{|T| = t} Π_i ind(F_i, G − T) = Σ_X ind(X, G)·Π_i ind(F_i, X) over the isomorphism types X on
n − t < n vertices, again Kelly. ∎

Source. This is the induced-subgraph form of Kocay's lemma (Kocay 1981; statement read in
Thatte 2005, Lemma 1.3, per `algebraic_methods.md` A2). The inclusion–exclusion form is my
derivation. Tested: X2 (two blocks).

### S1. Hamiltonian cycles (Tutte 1979)

**Claim.** c(G) := number of cyclic permutations ρ of V with x ~ ρx for all x (= 2·number
of Hamiltonian cycles for n ≥ 3) is the same for G and H.

Paper argument (edge subsets, no tuples with repetition). For a graph X and j ≥ 0 let
a_j(X) = number of j-edge subsets F ⊆ E(X) with (V(X), F) connected. A j-subset of E(G)
determines the partition of V into the components of (V, F), so with m = |E(G)|

    C(m, j) = Σ_π Σ_{(j_S), Σ j_S = j} Π_{S ∈ π} a_{j_S}(G[S]).            (1)

The one-block term is a_j(G). The rest is a partition sum with ≥ 2 blocks (S0, with
polynomial weights Σ_j a_j t^j), and C(m, j) is known (checked `kelly_edge_count`). So
**a_j(G) = a_j(H) for every j**: a_{n−1} is the number of spanning trees, a_n the number u of
spanning unicyclic subgraphs.

For 3 ≤ k ≤ n − 1 count pairs (C, F): C a k-cycle of G, F ⊆ E(G) ∖ E(C), |F| = n − k. There
are cyc_k(G)·C(m − k, n − k) of them, and cyc_k is a Kelly count (k < n). Split by the
components of (V, E(C) ∪ F) as in (1), with the block containing C marked. The one-block term
counts the connected spanning subgraphs with n edges whose cycle is C, i.e. the number u_k(G)
of spanning unicyclic subgraphs with cycle length k. The other terms are S0 sums. So
u_k(G) = u_k(H) for k < n, and

    c(G)/2 = a_n(G) − Σ_{k=3}^{n−1} u_k(G).   ∎

**This is the first graph-specific step.** An undirected connected spanning subgraph with n
edges and no pendant vertex is *the* Hamiltonian cycle: one isomorphism type, isolated by one
equation. For a digraph the spanning n-cycles come in many orientation types, and the
equation only gives their total (for a tournament the total is (n−1)!/2, a vacuous equation),
while the determinant needs the consistently oriented type alone.

Source. Tutte 1979 (Hamiltonian cycles, spanning trees, characteristic polynomial are
recognizable), simplified by Kocay 1981; both [V-sec] via Thatte 2005 (`algebraic_methods.md`
A2–A4). Primary texts UNVERIFIED. The edge-subset arrangement is mine. Tested: X3.

### S2. Characteristic polynomial (Tutte 1979)

**Claim.** φ(G) = φ(H).

Paper argument. Expand det(xI − A) over permutations and group by the partition into cycle
supports. A fixed point contributes x. A cycle of length ℓ ≥ 2 on S contributes
(−1)^{ℓ−1}·(−1)^ℓ = −1 times the product of its entries, so a block S with |S| ≥ 2
contributes −c(G[S]):

    φ(G; x) = −c(G) + P_g(G),   g(K₁) = x,  g(X) = −c(X) for |X| ≥ 2.     (2)

S1 gives the first term, S0 the second. No derivative formula is needed. ∎

Source: as S1. He 2007 (JCTB 97, 421–429; arXiv:math/0511475) states the theorem for all
real symmetric hypomorphic matrices, with tJ added: det(B − λI + tJ) = det(A − λI + tJ)
[search excerpt of the arXiv abstract page only; UNVERIFIED]. Tested: X1 (identity (2)).

### S3. Closed walks at each vertex

**Claim.** (A_G^k)_{vv} = (A_H^k)_{σv,σv} for all v, k.

Paper argument. adj(xI − A)_{vv} = φ(G − v) and (xI − A)·adj(xI − A) = φ(G)·I, so
Σ_k (A^k)_{vv} x^{−k−1} = φ(G − v)/φ(G). Now φ(G) = φ(H) by S2 and φ(G − v) = φ(H − σv)
because the cards are isomorphic. ∎ (Lean-friendly form: compare coefficients in
φ(G)·Σ_k (A^k)_{vv} x^{−k−1} = φ(G − v); induction on k, then Cayley–Hamilton for k ≥ n.)

### S4. Walks from each vertex (Godsil–McKay 1981)

**Claim.** (A_G^k·1)_v = (A_H^k·1)_{σv} for all v, k. In an aligned pair the walk matrices
W = [1, A1, …, A^{n−1}1] are equal, and Δ·A^k·1 = 0.

Paper argument. Let R = (xI − A)^{−1} over ℚ((1/x)) and y = −x − 1. Then
yI − Ā = −[(xI − A) + 1·1ᵀ], so by the rank-one update formulas

    φ(Ḡ; y) = (−1)^n φ(G; x)·(1 + 1ᵀR1),
    R̄(y)_{vv} = −R_{vv} + (e_vᵀR1)(1ᵀRe_v)/(1 + 1ᵀR1).                     (3)

Ḡ and H̄ are hypomorphic along the same σ (checked helper `card_compl_iso` in
`L_found_hypomorphic_compl`). S2 for both pairs gives 1ᵀR1; S3 for both pairs gives R_{vv} and
R̄_{vv}. **A is symmetric**, so e_vᵀR1 = 1ᵀRe_v and (3) gives (e_vᵀR1)². Its leading
coefficient is 1 > 0, so the series e_vᵀR1 = Σ_k (A^k1)_v x^{−k−1} is determined (solve for
the coefficients one at a time). Finally A w_k = w_{k+1} = A′ w_k for w_k = A^k 1. ∎

**This is the second graph-specific step**: for a digraph (3) only gives the product of the
out-walk series and the in-walk series of v.

Source. Godsil–McKay, JCTB 30 (1981) 285–289. Read in He, arXiv:math/0607142 (2006), Theorem
4 and Corollary 3 ("the orthogonal projection of 1 onto eigen_λ(A) equals [that] onto
eigen_λ(B)" for hypomorphic real symmetric A, B), full text read; primary UNVERIFIED. The
series argument above is my arrangement. Tested: X4 (identity (3) with exact arithmetic), and
`t3_pseudosimilar.py`: all 23796 vertex pairs with isomorphic cards on n = 8, including the
44 pseudo-similar pairs, have equal walk and closed-walk profiles (a non-vacuous instance of
S3/S4 with H = G and σ a transposition).

### S5. Walk matrix of rank ≥ n − 1 (Godsil–McKay class)

**Claim.** If rank W(G) ≥ n − 1 then G is reconstructible; in fact Δ = 0, so σ itself is an
isomorphism.

Paper argument. Δ is symmetric and ΔW = 0 (S4), so rank Δ ≤ n − rank W ≤ 1. If Δ_ij ≠ 0 with
i ≠ j, columns i and j of Δ are independent (column i is 0 in row i and non-zero in row j,
column j the reverse; the diagonal is 0). So Δ = 0. ∎

The second half is pure linear algebra about two labelled graphs with the same walk matrix
(**S5core**, formalizable now). Almost every graph has an invertible walk matrix (O'Rourke–
Touri, arXiv:1511.05080, Theorem 1.4; abstract and search excerpt only), and G(n, ½) lies in Q
with probability → 1 (standard, no source checked), so S5 covers asymptotically almost all of
Q. Like lemma C of t2 it is a "generic" class. Unlike lemma C it is graph-specific (§7).

Source: the reconstructibility of graphs with all eigenvalues simple and main is attributed
to Godsil–McKay 1981 (via Wang–Wen–Guo, arXiv:2408.02488, read in full, who quote Hong 1982
as "based on the work of Godsil–McKay"). The exact statement of the 1981 theorem is
UNVERIFIED; the argument above is self-contained given S4. Tested in labelled form
(`t3_walk_groups.py`, every labelled H′ with W(H′) = W(G), n ≤ 7): no H′ ≠ G when
rank W ≥ n − 1.

### S6. Rank n − 2: balanced block switches (my derivation)

**Claim.** Let rank W(G) = n − 2 and let (G, H′) be aligned with H′ ≠ G. Then there are
disjoint non-empty sets P₁, P₂, Q₁, Q₂ with |P₁| = |P₂|, |Q₁| = |Q₂| such that

- G has all edges P₁–Q₁ and P₂–Q₂ and no edges P₁–Q₂ and P₂–Q₁; H′ is G with these four
  bipartite blocks complemented; G and H′ agree on every other pair;
- p = 1_{P₁} − 1_{P₂} and q = 1_{Q₁} − 1_{Q₂} span the orthogonal complement of the walk
  vectors, and that complement is A-invariant: every vertex outside P ∪ Q has equally many
  neighbours in P₁ and P₂, and in Q₁ and Q₂.

If |P₁| = 1 or |Q₁| = 1, the transposition of P₁ ∪ P₂ (resp. Q₁ ∪ Q₂) maps G onto H′. So a
non-isomorphic H′ needs |P₁|, |Q₁| ≥ 2, hence n ≥ 8 and 4·|P₁|·|Q₁| ≥ 16 switched pairs.

Paper argument. rank Δ ≤ 2 and Δ ≠ 0, so rank Δ = 2 (S5). A real symmetric matrix of rank 2
is λ₁y₁y₁ᵀ + λ₂y₂y₂ᵀ; the zero diagonal forces opposite signs, so Δ = aaᵀ − bbᵀ with
a_i² = b_i², b_i = ε_i a_i, and Δ_ij = a_i a_j (1 − ε_i ε_j). Hence Δ lives between
S⁺ = {a ≠ 0, ε = +1} and S⁻ = {a ≠ 0, ε = −1} with Δ_ij = 2 a_i a_j = ±1 there, so |a| is
constant on each side and Δ_ij = s_i s_j for signs s. Δ1 = 0 makes both sides balanced. This
is the block shape with P = S⁺, Q = S⁻. ΔW = 0 and the independence of p, q give p, q ⟂ W; the
dimension gives span{p, q} = (col W)^⊥, which is A-invariant because A is symmetric and col W
is A-invariant. If P₁ = {p₁}, P₂ = {p₂}: (Ap)_x = 0 for x ∉ P ∪ Q says p₁, p₂ have the same
neighbours outside P ∪ Q; inside, p₁ is joined to Q₁ and not Q₂, p₂ the reverse; so
exchanging p₁, p₂ turns G into H′. ∎

The shape is that of the Wang–Qiu–Hu switching for cospectral graphs (Linear Algebra Appl.
563 (2019) 154–177; bibliographic record only, the resemblance is from memory, UNVERIFIED).
Tested in labelled form, n ≤ 7: all 52 + 8 + 5 + 1 labelled H′ ≠ G at corank 2 are balanced
block switches with a block of size 1, and the transposition maps G onto H′ every time.

### S5′. One card with spectral constraints (Hong 1982)

Fix v, A_c = adjacency matrix of the card G − v, b = indicator of N(v) in the card,
c = indicator of S := f_v^{−1}(N_H(σv)). So H ≅ (G − v) + S.

**Claim.** For all k: 1ᵀA_c^k b = 1ᵀA_c^k c and bᵀA_c^k b = cᵀA_c^k c. (Walks in the card
starting in N(v), and walks from N(v) to N(v), are counted the same for S.)

Paper argument. Schur complement: φ(G) = φ(G − v)·(x − bᵀR_c b), so S2 gives
bᵀR_c b = cᵀR_c c. The same for the complements with 1 − b, 1 − c, and (3) applied to the
card, gives (1 + bᵀR_c1)² = (1 + cᵀR_c1)²; the leading coefficients are 1. ∎

Consequence (Hong, JCTB 32 (1982) 245–256, as quoted in Wang–Wen–Guo arXiv:2408.02488,
Theorem 4, read in full): if the walk matrix of some card has full rank n − 1, then b = c and
G is reconstructible. Wang–Wen–Guo Theorem 6 extends this to cards of walk rank n − 2 with a
non-trivial automorphism. Tested: X5 (every S whose re-attachment has the two characteristic
polynomials of G and Ḡ satisfies the walk-count equalities, n ≤ 7 exhaustive).

## 3. Chain D: diameter 2 in G and Ḡ, with the level counts (all n ≥ 3)

### D1. Codegree counts of non-adjacent pairs

**Claim.** If Ḡ is connected, then for every j the number q_j of non-adjacent pairs with
exactly j common neighbours is the same for G and H.

Paper argument. M_j := Σ over non-adjacent pairs of C(codeg, j) = Σ_{|W| = j+2} μ(G[W]),
where μ(X) = number of non-adjacent pairs of X adjacent to every other vertex of X. For
j + 2 < n this is a Kelly sum. For j + 2 = n, μ(G) counts the K₂-components of Ḡ, which is 0
for G and for H (connectedness of the complement is recognizable: checked
`connected_recognizable` and `found_hypomorphic_compl`). Binomial inversion:
q_j = Σ_{i ≥ j} (−1)^{i−j} C(i, j) M_i. ∎ (t1 S1 and t2 §1 have the same argument in two
other forms; both were tested there.)

### D2. Q is recognizable

q₀(G) = 0 ⇔ diam G ≤ 2. Apply D1 to G and to Ḡ. (Gupta–Mangal–Paliwal 2003 via
arXiv:2601.00620; primary UNVERIFIED; the argument is D1.)

### D3. Forced sets

For G ∈ Q and a vertex v, computed **from the card G − v alone**:

- F⁺(v) = all x that lie in a non-adjacent card pair {x, y} with no common neighbour in the
  card. Then F⁺(v) ⊆ N(v): the common neighbour that diam G ≤ 2 demands can only be v.
- F⁻(v) = all x that lie in an adjacent card pair {x, y} with no common non-neighbour in the
  card. Then F⁻(v) ∩ N(v) = ∅: the common non-neighbour that diam Ḡ ≤ 2 demands is v.

A card isomorphism f_v maps F^±_G(v) onto F^±_H(σv), and H ∈ Q by D2, so
f_v(F⁺_G(v)) ⊆ N_H(σv) and f_v(F⁻_G(v)) ∩ N_H(σv) = ∅.

This is the "diameter-2 identity" in the only form in which I could make it bite: it is an
inequality (codegree ≥ 1), and it carries information exactly at the pairs where it is tight
in the card.

### D4. Condition (★₂)

Level L_k = vertices of card-degree k in G − v. Lemma B (t1 K1 step 3) gives
|S ∩ L_k| = |N(v) ∩ L_k| for S = f_v^{−1}(N_H(σv)).

**(★₂) at v:** for every level L_k, either N(v) ∩ L_k ⊆ F⁺(v) or L_k ∖ N(v) ⊆ F⁻(v).

Then S = N(v): on a level of the first kind S ⊇ F⁺ ∩ L_k ⊇ N ∩ L_k with equal cardinalities;
on a level of the second kind S ⊆ L_k ∖ F⁻ ⊆ N ∩ L_k with equal cardinalities. (★) of t1 is
the special case where each level is inside N(v) or disjoint from it.

### D5. Unique feasible neighbourhood (the class to formalize)

Call S ⊆ V ∖ {v} **feasible at v** if (a) |S ∩ L_k| = |N(v) ∩ L_k| for every k and (b) the
graph (G − v) + S has both diameters ≤ 2.

**Claim.** If G ∈ Q and at some v every feasible S is the image of N(v) under an automorphism
of the card G − v, then G is reconstructible.

Paper argument. S := f_v^{−1}(N_H(σv)) is feasible: (a) is lemma B, (b) holds because
(G − v) + S ≅ H and H ∈ Q (D2). Take the automorphism e of G − v with e(N(v)) = S; then
f_v ∘ e maps N_G(v) onto N_H(σv) and extends by v ↦ σv (the construction of the checked
`iso_of_card_iso_of_isolated`, with a neighbourhood hypothesis). ∎

(★₂) ⇒ only S = N(v) is feasible ⇒ D5. The automorphism clause matters: on n = 8 it raises
D5 from 215 to 217 of the 218 graphs of Q, and the remaining graph, the self-complementary
`GhEJ]o` (|Aut| = 8), has at every card exactly one other set passing (a), (b) and the
constraints of S5′, which is the image of N(v) under a card automorphism.

No source found for D3–D5. Monikandan–Balakumar 2014 treat geodetic blocks of diameter 2
(abstract only, `structural_reductions.md` S5), where every codegree is tight; D5 is the
"partly tight" version. Tested: X6.

## 6. Where every attempt stops

1. **Δ = 0 from spectra (chain S).** Stops at rank W ≤ n − 2. Vertices with isomorphic cards
   have equal rows of W (S4 with a transposition), so corank W ≥ n − (number of card types):
   every graph with two disjoint pairs of similar or pseudo-similar vertices is outside S5,
   and every regular graph has rank W = 1. The spectral data of this chain amount to: for
   every root v there is an orthogonal Q_v with Q_v 1 = 1, Q_v e_v = e_v and Q_vᵀAQ_v = A′
   (Wang–Wen–Guo arXiv:2408.02488, Theorem 3, read in full). The set of all such Q is a coset
   of a product of orthogonal groups acting on the non-main eigenspaces; nothing spectral
   forces a permutation matrix in it. At corank 2 the obstruction is explicit (S6): a
   balanced block switch with both blocks ≥ 2 + 2. I found no argument against it, and I see
   no way for the diameter hypotheses to exclude it: the switch keeps the codegree of every
   pair made of an outside vertex and a vertex of P ∪ Q.
2. **The diameter-2 identity in matrix form.** "Every non-adjacent pair has a common
   neighbour, in G and in Ḡ" reads A² + A ≥ J − I and Ā² + Ā ≥ J − I entrywise. These are
   inequalities; they give no linear or polynomial identity for Δ, and G and H′ satisfy them
   alike (D2). They carry information only where they are tight (D3). In the residual every
   card has slack: some other S keeps all codegrees ≥ 1 on both sides.
3. **Kocay's covering lemma plus diameter 2.** Diameter 2 gives a spanning tree of depth 2
   at every vertex, but Kocay counts only disconnected spanning subgraphs and (S1) connected
   ones by number of edges, not by tree type. For a tree T only one of s(T, G),
   s(T, G) ± s(T, Ḡ) is claimed recognizable (Stark, arXiv:2509.02604, Theorem 3; an
   unrefereed claim per `algebraic_methods.md` A12). Counting rooted depth-2 spanning trees
   is exactly the unknown "top layer" of `hom_counts_and_logic.md`.
4. **Merging lemma B with S4: fails on an explicit graph.** Lemma B says Δ·1_{D_k} = 0; S4 says Δ·A^j·1 = 0.
   The natural common statement "Δ·A^j·1_{D_k} = 0", i.e. *the number of walks of length j
   from v ending in a vertex of degree k is determined by the card G − v and the deck*, fails
   (tested; a decidable fact about one graph, not checked). Witness: G = `GGOglg` (n = 8, asymmetric), vertices 3 and 4. Their cards are
   isomorphic, so the transposition (3 4) is a hypomorphism G → G; the number of walks of
   length 2 ending in a vertex of degree 1 is 1 from vertex 3 and 0 from vertex 4. All 44
   pseudo-similar pairs on 8 vertices show a mismatch (`t3_degree_walks.py`). This is a
   statement about one graph and can be turned into a decidable Lean fact if the candidate
   lemma is ever proposed as a step (its negated twin would then be the target). Reason it fails: a card isomorphism preserves card
   degrees, not G-degrees; lemma B survives only because the degree drops by exactly [x ~ v].
   What does survive: seeds that every card isomorphism respects, e.g. the classes of a
   partition of the degree set into runs of consecutive integers. With He's weighted form of
   Tutte's theorem (UNVERIFIED) this would give Δ·w = 0 for w in the span of
   {(A + Σ s_i·diag 1_{R_i})^k·1}; I did not work this out fully and do not rely on it. It
   is empty when the degrees form one run.
5. **One card with everything (D5 + S5′).** Stops at R⁺ (§4): a semantic-free but unexplored
   class. No member known; no argument that it is empty.
6. **Two cards.** Not attempted here; see lemma C of t2 and the twists of t4.

## 7. What breaks for tournaments, 3-uniform hypergraphs, infinite graphs

Computed, not remembered (`t3_tournament_check.py`, all tournaments on 5 and 6 vertices,
grouped by deck; 12 classes / 11 decks and 56 / 52, matching `algebraic_methods.md` A11):

| n | pair | characteristic polynomial | directed Hamiltonian cycles | closed walks by card (S3) | out-walks by card (S4) | rank of out-walk matrix |
|---|---|---|---|---|---|---|
| 5 | the one pair | constants −3 vs −2 | 3 vs 2 | – | – | – |
| 6 | all four pairs | equal | equal | agree | **disagree** | 6, 4, 6, 6 |

- **Tournaments.** At n = 5 the chain breaks at S1/S2 (Hamiltonian cycles: orientation
  types). At n = 6 S1–S3 hold and S4 fails: (3) needs e_vᵀR1 = 1ᵀRe_v. Three of the four
  pairs have an invertible out-walk matrix, so a tournament version of S5 would contradict
  their existence; the symmetry of A is exactly what S5 rests on. S5core also uses symmetry
  (for tournaments Δ is skew-symmetric and can have rank 2 with zero diagonal).
- **Chain D is not graph-specific.** Scores replace degrees in lemma B (t2 §7), and "every
  arc lies on a directed triangle" replaces the diameter condition; forced sets exist there
  too. So D1–D5 cannot be what closes the step, and Stockmeyer's tournaments must sit in the
  tournament analogue of R. Only R⁺ (through S5′) and S5, S6 use graph-specific input.
- **3-uniform hypergraphs.** No symmetric matrix M with "M(G − v) is the principal submatrix
  of M(G)" determines the hypergraph (the pair-codegree matrix changes on deleting v). The
  hypergraph characteristic polynomial is not recognizable (Cooper–Okur, arXiv:2312.16152,
  abstract only per `algebraic_methods.md` A11). Lemma B's level counts break too (t2 §7).
- **Infinite graphs.** Kelly's division, determinants and finite walk counts are all
  unavailable.
- **Nýdl-type check.** S2–S5 use full cards (φ(G − v) for every v) and the count c(G) on all n
  vertices; D5 uses one full card. Nothing here would work from a fixed fraction of n.

## 10. Where this could break

1. **S1 is the long pole and is only sketched.** The marked-block splitting for u_k is the
   least routine step; X3 tests the resulting identity for n ≤ 6, not the splitting itself.
2. **S4's sign step** needs the leading coefficient; fine over ℚ((1/x)), but a Lean proof
   should avoid power series and solve for coefficients by induction.
3. **D5's clause (b) is long.** Four conjuncts encode "(G − v) + S ∈ Q". A slip there cannot
   make a false result checked, but would make the class smaller or the residual wrong.
   `t3_lib.feasible_sets` implements (b) by rebuilding the graph, so the statistics test the
   intended class, not the Lean text.
4. **R and R⁺ are over-approximations**: membership does not require a non-isomorphic
   re-attachment, so they contain graphs that t2's one2 already handles.
5. **Attributions.** Godsil–McKay 1981, Hong 1982, Tutte 1979, Kocay 1981, Wang–Qiu–Hu 2019
   were not read in the primary text. S5, S6, D3–D5 are stated with self-contained paper
   arguments so that soundness does not depend on them.
6. **S6 beyond corank 2.** At corank c the same argument gives only rank Δ ≤ c; I have no
   classification for c ≥ 3 (the labelled data for n ≤ 7 show rank Δ from 2 up to c).
