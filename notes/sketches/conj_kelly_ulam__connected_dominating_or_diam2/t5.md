## 1. Lemma G without telescoping (paper argument)

Fix G on n ≥ 3 vertices, a graph F (a *type*), and a ≥ 0. Over ordered pairs (x, y), x ≠ y,
with G − x − y ≅ F, write m = e(F), E = e(G) and

- P = all type-F pairs,
- E_a = the adjacent type-F pairs with deg x = a,
- X = the type-F pairs with deg x ≥ a,
- Y = the type-F pairs with deg y + a + m ≥ E + 1.

**Bit law** (t4 §3, single graph): for a type-F pair, m + deg x + deg y = E + [x ~ y].

**Cut identity.** X ∩ Y = E_a and X ∪ Y = P. Hence |E_a| + |P| = |X| + |Y|.

- X ∩ Y ⊆ E_a: deg x ≥ a and deg y ≥ E + 1 − a − m give m + deg x + deg y ≥ E + 1, so
  [x ~ y] = 1 and the sum is exactly E + 1, which forces deg x = a.
- E_a ⊆ X ∩ Y: deg x = a, and the bit law with [x ~ y] = 1 gives deg y + a + m = E + 1.
- P ⊆ X ∪ Y: if deg x ≤ a − 1 and deg y + a + m ≤ E, then m + deg x + deg y ≤ E − 1 <
  E + [x ~ y], which contradicts the bit law.

**Invariance.** |P| and |X| are counts of type-F pairs whose *first* vertex satisfies a degree
condition. They are deck invariants by t4's L1, the bijection (x, y) ↦ (σx, f_x y), which keeps
the type and the first degree (T0). The swap (x, y) ↦ (y, x) keeps the type, so |Y| equals the
number of type-F pairs with deg x + a + m ≥ E + 1, also a first-vertex condition. E = e(G) =
e(H) by `L_kelly_edge_count`. So |E_a(F)| is a deck invariant, which is Lemma G.

Compared with t4 §3, this has no induction on a, no subtraction s − a, and no case a > s. In
Lean it is one `Set.ncard_union_add_ncard_inter` plus two set equalities closed by `omega`.

**Tested** (`t5_check.py`): the two set equalities and the swap count, for every graph, every
type and every a ∈ [0, n]. NO WITNESS, exhaustive n = 3..7 (1249 graphs, 78202 (type, a) cases).

**What breaks for tournaments, hypergraphs, infinite graphs.** The cut identity's only
graph-specific input is the bit law. That is exactly t4's §10 ingredient, and t4 tested that it
fails for Stockmeyer's tournaments. Nothing new is claimed here.

## 2. Lemma P from Lemma G (paper argument, as in t4 §4, written for the Lean draft)

Let u have pure degree a = deg u, and let w ≠ u, F := G − u − w. Then (σu, f_u w) is a type-F
pair of H with first degree a (T0, plus restricting f_u). If u ~ w, then every type-F pair of G
with first degree a is adjacent (purity). So E_a(F; G) = P_a(F; G), the two counts are equal in
H, and E_a(F; H) ⊆ P_a(F; H) is finite, so the sets are equal and σu ~ f_u w. If u ≁ w, then
E_a(F; G) = ∅, so E_a(F; H) = ∅ and σu ≁ f_u w. Hence N_H(σu) = f_u(N_G(u)), and f_u extends by
u ↦ σu to G ≅ H (the extension generalizes the checked helper `iso_of_card_iso_of_isolated`).

## 4. Lean draft for `pure_degree_class`

`lean/Recon/Scratch/conj_kelly_ulam__connected_dominating_or_diam2__pure_degree_class/b1.lean`,
about 350 lines. It imports only Mathlib, the child's statement, `L_kelly_edge_count` and
`L_kelly_card_edges_add_degree`. Helpers:

| Helper | Content |
|---|---|
| `iso_induce_compl`, `iso_nested`, `iso_two` | a card isomorphism restricts to G − x − y ≅ H − σx − f_x y |
| `card_add_deg`, `nbr_card`, `bit_law` | the bit law, through the nested card (generic `Fintype` copy of the checked card/degree lemma) |
| `deg_tie` | T0, as in `L_kelly_degree_sequence` |
| `pairs`, `pairs2`, `adjPairs` | typed pair sets |
| `transfer` | L1 via `Set.ncard_congr` |
| `swap_card` | the swap via `Set.ncard_congr` and `Set.pair_comm` |
| `cut` | §1, via `Set.ncard_union_add_ncard_inter` |
| `adj_transfer` | Lemma G |
| `iso_of_card_iso_of_nbr` | the extension lemma |

Likely points of failure, for the builder:
1. The rewrite chain in `card_add_deg` is copied from `L_kelly_card_edges_add_degree` and
   generalized from `Fin n` to any `Fintype V`. Instance mismatches on the subtype are possible.
2. Defeq-reliant `show` steps on subtype membership (`iso_induce_compl`, `iso_nested`).
3. `rw [hew] at i` in `transfer` (rewriting inside the type of an isomorphism).
4. Lemma names that may have moved in Mathlib v4.36.0: `Set.ncard_congr`,
   `Set.ncard_preimage_of_injective_subset_range`, `Set.ncard_diff_singleton_add_one`,
   `Set.eq_of_subset_of_ncard_le`, `Set.eq_empty_of_forall_notMem`.
