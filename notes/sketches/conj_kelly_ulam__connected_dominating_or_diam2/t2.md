# t2: the diameter-2 branch of `conj_kelly_ulam__connected_dominating_or_diam2`

Thinker sketch, 2026-11-25. Angle: the disjunct "every pair at distance ≤ 2 in G and in Ḡ",
cross-field. **This is a sketch, not a result.** Nothing here is checked. The step is an open
core of the conjecture; this file gives a further *reduction plan* and an honest residual, not
a route to closing the step.

Step record: `frozen`, no dead ends, no earlier sketches. Vocabulary follows CLAUDE.md §1.
"Tested" below always means small-graph search (evidence only). "Elaborates" means a scratch
file compiled with `lake env lean`; it says nothing about the gate.

Write **D2** for the class `∀ u v, G.edist u v ≤ 2 ∧ Gᶜ.edist u v ≤ 2` and **DE** for the
class "G, Ḡ connected and G has a dominating edge".

## 0. Verdict in five lines

1. No known reconstructible class, and no recognizable invariant on the fleet's list, closes D2.
   D2 contains almost every graph (G(n, ½) has both diameters 2 with probability → 1; standard
   fact, no source checked), so it *is* the generic case.
2. Yang 1988, Bondy 1969, pendant vertices and vertices of degree n − 2 do not bite at all:
   every D2 graph and its complement are 2-connected with 2 ≤ δ ≤ Δ ≤ n − 3 (§1, tested).
3. Two paper arguments that need only the checked Kelly machinery do bite:
   **(B)** the degrees of the neighbours of each vertex are recognizable, so any graph that one
   card plus this data determines is reconstructible (covers regular graphs and every D2 graph
   I could generate, §4);
   **(C)** a two-card gluing lemma in the style of Müller 1976 / Bollobás 1990 (covers the
   asymptotically generic graph).
4. Proposed reduction: children A (DE, open), B (lemma, formalizable now), C (class,
   formalizable now), D (D2 residual, open). The implication elaborates in a scratch file (§5).
5. Neither B nor C is graph-specific: both are counting plus rigidity and have tournament
   analogues. All graph-specific difficulty is pushed into D (and A). See §7.

## 1. Anatomy of D2 (single-graph facts, all tested)

Paper arguments, each three lines; tests in `t2_claim_structure.py`
(NO WITNESS, exhaustive n = 2..7 plus 3000 random graphs each on n = 8, 9, 10, 11).

- **S3. D2 ⇔ neither G nor Ḡ has a dominating edge** (n ≥ 2). `diam Ḡ ≤ 2` says every edge uv
  of G has a common non-neighbour, i.e. uv is not dominating; symmetric for G. So the two
  disjuncts of the frozen statement are *disjoint* (S4), and the frozen class is "G, Ḡ
  connected, and not (Ḡ has a dominating edge while G has none)".
- **S1. D2 ⇒ n ≥ 5 and 2 ≤ δ(G) ≤ Δ(G) ≤ n − 3.** If v is pendant with neighbour w and
  diam G ≤ 2, then w is adjacent to everything, so Ḡ is disconnected. Apply to Ḡ for Δ.
  So "pendant structure" and "a vertex of degree n − 2" never occur in D2. C₅ is the unique D2
  graph on 5 vertices.
- **S2. D2 ⇒ every card of G and of Ḡ is connected** (G and Ḡ are 2-connected). If x is a cut
  vertex and diam G ≤ 2, pairs across two components of G − x have x as their only common
  neighbour, so x is universal.
  Consequence: Yang Yongzhi 1988 (reduce to 2-connected graphs) and Bondy 1969 (separable
  graphs without end vertices) say nothing about D2. D2 already lies inside Yang's target
  class, and inside the "diam G = diam Ḡ = 2" half of Aravind–Monikandan arXiv:2601.00620
  Theorem 7; their "2-connected" qualifier is automatic on this half.
- **D2 is recognizable** (not needed below, `ClassReconstructible` quantifies over all H). Let
  q_j = number of non-adjacent pairs with exactly j common neighbours. Then
  Σ_x q_j(G − x) = (n − 2 − j)·q_j + (j + 1)·q_{j+1} for 0 ≤ j ≤ n − 3. The system has a
  one-dimensional kernel (−1)^j·C(n−2, j) (the usual Kelly-type obstruction), pinned by
  q_{n−2} = number of K₂ components of Ḡ = 0 when Ḡ is connected. Tested:
  `t2_claim_pair_counts.py`, NO WITNESS. Literature: Gupta–Mangal–Paliwal 2003 via
  arXiv:2601.00620 Theorem 1 (pv, pav reconstructible); read in the arXiv HTML summary only,
  primary UNVERIFIED.

## 3. The two paper lemmas

### Lemma B (neighbour-degree data is recognizable)

Let n ≥ 3 and let σ be a hypomorphism G → H with card isomorphisms f_x : G − x ≅ H − σx. Then
for every v and k, v has as many neighbours of G-degree k as σv has neighbours of H-degree k.

Paper argument (all inputs checked or elementary):
1. e(G) = e(H) (`L_kelly_edge_count`), and deg_G(x) = deg_H(σx) for the *same* σ
   (`L_kelly_card_edges_add_degree` twice plus "isomorphic graphs have equally many edges",
   exactly as in the body of `L_kelly_degree_sequence`).
2. Fix v. For x ≠ v: deg_{G−v}(x) = deg_G(x) − [x ~ v]. Put
   A_k = #{x ~ v : deg_G x = k}, B_k = #{x ≁ v, x ≠ v : deg_G x = k},
   n_k = #{x : deg_G x = k}, c_k = #{x ≠ v : deg_{G−v} x = k}. Then
   n_k = A_k + B_k + [deg_G v = k] and c_k = A_{k+1} + B_k.
3. n_k, c_k and deg v agree for (G, v) and (H, σv) (step 1 for n_k, f_v for c_k). A_0 = 0 on
   both sides. Induction on k: A_k equal ⇒ B_k equal ⇒ A_{k+1} equal. Each step is `omega`.

Tested in strong form (N1 in `t2_claim_sep.py`): the multiset of neighbour degrees of v equals
the value of the recursion a_{k+1} = a_k + c_k − n_k + [deg v = k], a_0 = 0, for every (G, v);
NO WITNESS, exhaustive n = 3..7 plus 1500 random graphs each on n = 8, 9, 10.

Fails at n = 2 (K₂ versus 2K₁), so `3 ≤ n` is needed.

Corollaries (paper, not needed for the reduction):
- **one-card class.** If some v has the property "every H with a bijection τ such that
  H − τv ≅ G − v and the neighbour-degree data of H along τ equals that of G is isomorphic to
  G", then G is reconstructible. Immediate from Lemma B. Call this class **one2**.
- **degree separation.** If no neighbour u and non-neighbour w ≠ v of v satisfy
  deg w + 1 = deg u, then G ∈ one2 at v. Argument: with N″ = f⁻¹(N_H(τv)), P = N(v) ∖ N″,
  Q = N″ ∖ N(v) and d = degree in the card, the degree multisets force
  {d+1 on P} ⊎ {d on Q} = {d on P} ⊎ {d+1 on Q}; at the maximum value this gives p ∈ P, q ∈ Q
  with d(q) = d(p), i.e. deg q + 1 = deg p. So P = Q = ∅ and f extends by v ↦ τv.
  Tested in strong single-card form (`t2_claim_sep.py`, NO WITNESS).
- **regular graphs** are degree-separated at every vertex.

### Lemma C (unique two-deleted subgraph)

Let n ≥ 3, u ≠ v, S = V ∖ {u, v}, F = G[S]. Assume
(i) S is the only vertex set T with G[T] ≅ F, and
(ii) every automorphism of F maps N(u) ∩ S onto itself.
Then G is reconstructible.

Paper argument. Let σ, f_x be a hypomorphism to H.
1. Kelly's induced count (`L_conj_kelly_ulam__disconnected__kelly_induced_count`, checked,
   k = n − 2 < n) transfers "exactly one vertex set induces F" from G to H. Call it S_H.
2. f_u(S) and f_v(S) both induce copies of F in H, so both equal S_H. Hence
   V ∖ {σu, f_u(v)} = V ∖ {σv, f_v(u)}, and σu ≠ σv gives f_u(v) = σv, f_v(u) = σu.
3. g = f_v⁻¹ ∘ f_u restricted to S is an automorphism of F. Define φ = f_u on V ∖ {u},
   φ(u) = σu. For y ∈ S: G.Adj u y ⇔ G.Adj u (g y) by (ii) ⇔ H.Adj (f_v u) (f_v (g y)) =
   H.Adj (σu) (f_u y). Pairs inside V ∖ {u}: f_u.
4. The pair {u, v}: φ maps N_G(u) ∩ S bijectively onto N_H(σu) ∩ S_H (step 3), and
   deg_G(u) = deg_H(σu), so [u ~ v] = [σu ~ σv].

Special case W: F asymmetric (then (ii) is vacuous). This is the deterministic core of the
"almost every graph" theorems.

Tested in a strong form that does not presuppose a deck (`t2_claim_two_deleted.py`): for G with
(ii) at (u, v), every one-vertex extension H′ of G − u that has a second card ≅ G − v, the
right degree at the new vertex and exactly one copy of F is isomorphic to G. NO WITNESS,
exhaustive n = 4..7 plus 150 random graphs each on n = 8 and 9 (slow: tens of minutes for
n = 7).
These four facts about H′ are exactly what the paper argument uses.

  ambiguous at every card and non-rigid at every two-deleted subgraph.

Hypothesis **H\*** (NOT relied on; a red-team target): every D2 graph is in one2. Claim file

child: a false child kills the reduction.

### A. `dominating_edge` — OPEN (the other branch; not analysed here)

### B. `nbr_degree_recognizable` — FORMALIZABLE NOW (own derivation; no source found)

```lean
∀ n : ℕ, 3 ≤ n → ∀ G H : SimpleGraph (Fin n), ∀ σ : Fin n ≃ Fin n, (∀ x : Fin n, Nonempty (Recon.card G x ≃g Recon.card H (σ x))) → ∀ (v : Fin n) (k : ℕ), {y : Fin n | G.Adj v y ∧ (G.neighborSet y).ncard = k}.ncard = {y : Fin n | H.Adj (σ v) y ∧ (H.neighborSet y).ncard = k}.ncard
```

### D. `diam2_ambiguous` — OPEN (the minimal honest residual of this sketch)

```lean
Recon.ClassReconstructible (fun n G => (∀ u v : Fin n, G.edist u v ≤ 2 ∧ Gᶜ.edist u v ≤ 2) ∧ (∀ v : Fin n, ∃ H : SimpleGraph (Fin n), ∃ τ : Fin n ≃ Fin n, Nonempty (Recon.card G v ≃g Recon.card H (τ v)) ∧ (∀ (x : Fin n) (k : ℕ), {y : Fin n | G.Adj x y ∧ (G.neighborSet y).ncard = k}.ncard = {y : Fin n | H.Adj (τ x) y ∧ (H.neighborSet y).ncard = k}.ncard) ∧ ¬ Nonempty (G ≃g H)) ∧ ∀ u v : Fin n, u ≠ v → (∀ T : Finset (Fin n), Nonempty (G.induce ({u, v}ᶜ : Set (Fin n)) ≃g G.induce (T : Set (Fin n))) → (T : Set (Fin n)) = {u, v}ᶜ) → ∃ e : G.induce ({u, v}ᶜ : Set (Fin n)) ≃g G.induce ({u, v}ᶜ : Set (Fin n)), ∃ x : ({u, v}ᶜ : Set (Fin n)), ¬ (G.Adj u (e x).1 ↔ G.Adj u x.1))
```
English: D2 graphs such that (a) at *every* vertex v some non-isomorphic H shares the card at
v and the full neighbour-degree data, and (b) no two-deleted subgraph is both unique and
neighbourhood-rigid. No member is known (§4). Free extra facts about members, available to
whoever attacks D: S1–S3 of §1 (2-connected, co-2-connected, 2 ≤ δ, Δ ≤ n − 3, not regular,
not degree-separated at any vertex), and n ≥ 8 by the exhaustive one2 run on n ≤ 7. Note that
membership in D does not require G to be non-reconstructible, so the n ≤ 13 verification of the
conjecture says nothing about whether D has small members.

### Kernel implication `R_…_r1 : A → B → C → D → S_parent` (about 30 lines, elaborates)

```
intro hA hB hC hD n hn G ⟨hc, hcc, hdis⟩
rcases hdis with hde | hd2
· exact hA n hn G ⟨hc, hcc, hde⟩
by_cases hOne : ∃ v, ∀ H τ, Nonempty (card G v ≃g card H (τ v)) → (data equal along τ) → Nonempty (G ≃g H)
· obtain ⟨v, hv⟩ := hOne; intro H ⟨σ, hσ⟩; exact hv H σ (hσ v) (hB n hn G H σ hσ)
by_cases hC' : (the class of C holds for G)
· exact hC n hn G hC'
exact hD n hn G ⟨hd2, (push the two negations), ...⟩
```
No graph theory is needed in the R-file: only `by_contra` to turn `¬ ∃ v, ∀ H τ, …` into
`∀ v, ∃ H τ, …`.

### Variants the reducer may prefer

- **Shrink A for free.** Do the two `by_cases` before splitting DE / D2; then A becomes
  "DE ∧ ambiguous ∧ no unique rigid two-deleted subgraph". This also elaborates. The n = 8
  graphs in §4 are members of that shrunk A, so it is not vacuous.
- **Combinatorial residual instead of semantic.** Replace B by the class
  `∃ v, ∀ u w, G.Adj v u → w ≠ v → ¬ G.Adj v w → (G.neighborSet w).ncard + 1 ≠ (G.neighborSet u).ncard`
  (degree separation; elaborates) and D's clause (a) by its negation. The residual is then
  easier to read and has explicit members at n = 7 (`FdZKO`, `Fhff?`), but it is strictly
  larger and grows with n.
- **Free strengthening of D.** Add to the ambiguous H in (a) the conjunct "H and G have the same
  induced counts for all F on k ≤ n − 2 vertices". The R-file then also applies the checked
  Kelly count; no new lemma. With k ≤ n − 1 the clause would become a restatement of
  hypomorphism and the child would restate the problem, so stop at n − 2.

## 6. Where this could break

1. **D may be unattackable as stated.** Clause (a) is semantic (∃ H). The reduction moves all
   difficulty into D without giving a handle on it. It is honest, but a strategist should not
   count D as "smaller" in any sense that makes it easier; it only removes what B and C cover.
2. **D may be empty in every testable range.** Then the red team cannot screen D, and
   `claim_pair` tests are vacuous anyway (the conjecture holds for n ≤ 13). The useful red-team
   job is H\*: find a D2 graph outside one2 (needs geng for exhaustive n = 8, 9, or structured
   families: non-regular graphs with few degree values and many automorphism-free ambiguities).
3. **Lean risk in B**: `ncard` over set-builder sets; the partition identities need finiteness
   side goals. Fallback: `classical`, convert to `Finset.filter` cards once, then `omega`.
4. **Lean risk in C**: (i) Kelly's checked statement wants F on `Fin k`; transport
   `G.induce {u,v}ᶜ` along `Fintype.equivFinOfCardEq`. (ii) `{u, v}ᶜ` as a `Set` versus a
   `Finset` coercion in the count. (iii) restricting a card isomorphism to S and composing two
   of them into an automorphism of F. If C stalls, drop it; the 3-child reduction stands.
5. **Children of a reduction get no fidelity review.** D is long. A wrong D cannot make a false
   result checked (the implication is kernel-checked), but it can waste effort. The tie
   "card at v ↔ τ v" in D is deliberate: it is what the hypomorphism provides and it makes D
   smaller than the untied version my scripts test (so the tests are conservative).
6. **Citations.** Müller 1976 and Bollobás 1990 were not read; the link to Lemma C is from
   memory of the proof idea (`groups_and_harmonic.md` also marks it UNVERIFIED). Lemma B has no
   source. Neither matters for soundness, only for attribution.

## 7. What is graph-specific (the counting-only warning)

- **Lemma B is binary-edge-specific but not graph-specific.** It uses that deleting v lowers
  the degree of x by exactly [x ~ v], so a vertex statistic of the card exposes the deleted
  adjacencies up to ties. For 3-uniform hypergraphs the drop is a codegree and the lost
  information is a set of pairs, so the recursion breaks. For tournaments the analogue with
  scores holds verbatim (the scores of the out-neighbours of v are recognizable).
- **Lemma C is counting plus rigidity** and holds verbatim for tournaments and digraphs.
- Therefore B and C cannot close the step: Stockmeyer's tournaments must lie in the tournament
  analogue of the residual (ambiguous at every card, no unique rigid two-deleted
  subtournament). Any argument for D has to use something tournaments lack. Candidates on the
  fleet's map: complement/distance structure (D2 itself has no tournament analogue: S3 says
  neither G nor Ḡ has a dominating edge), and the spectral input (Tutte's characteristic
  polynomial; not formalizable soon).
- Nýdl-type warning: both lemmas use near-full information (one or two full cards, the
  (n−2)-deck count), consistent with "no fixed fraction of the vertices suffices".
- Infinite graphs: B divides nothing but uses finite counts and induction on k; C uses Kelly's
  finite count. Both fail to make sense for infinite graphs, as they should.
