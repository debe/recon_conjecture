## What the round learned

1. **SCL is exactly "Q is a cut".**
   - Under H1, every isomorphism G^Q → G is a partial swap π_S (t4 Prop ISO, t5 Lemma R).
   - So "G^Q ≅ G up to a cover automorphism" adds nothing.
   - If [Q] ≠ 0, then every card map at every vertex moves some vertex to a different τ-orbit, and the moved set meets the lift of every Q-odd cycle (Lemma T).
2. **The missing lemma, ML.** SCL is equivalent to this: under H1, with Q not a cut, some vertex x, some card map f : G^Q − x → G − x and some Q-odd cycle Z exist with f preserving τ-orbits on the lift of Z ∖ x. With ML, Lemma T gives a contradiction, so Q is a cut.
   - This is the hard core in its smallest form. The cards must force one fibre-respecting map.
   - Walk data cannot do it, because by Lemma N it is blind inside the walk hull of the swap δ_x.
3. **Walk data are provably blind to [Q]** (recorded as a dead end). Two families show it:
   - CFI-type negative-4-cycle necklaces (t5 N1);
   - Hadamard signatures on K₄,₄ (t4).
4. **A new tool that is not a count: FPK (fixed-point Kelly).** τ is an automorphism of both G and G^Q. So for every X on fewer than n vertices, the numbers of τ-invariant vertex sets W with G[W] ≅ X and with G^Q[W] ≅ X agree mod 2.
   - Main-session check: τ pairs up the non-invariant W, and Kelly's induced count (checked) equates the totals. Correct.
   - It yields "Q is a cut" when a deleted graph is orbit-rigid (FPD, ONE, FP). H1 does not supply that rigidity.
5. **Profile of a counterexample** (t5 §6). The base must be asymmetric, and every single deletion must create a fibre-breaking isomorphism in the wrong double coset Λ_A τ Λ_A. Neither thinker found a contradiction in that profile, or an instance of it.
6. **Why the known twists do not transfer to graphs** (scout + t5):
   - Stockmeyer puts the twist inside one antipodal pair, but a graph card knows the degree of the missing vertex, and a tournament has no involutory automorphism to run FPK on.
   - Kocay 1987 puts it in a vertex link, which for a graph is only a set.
